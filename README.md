# Agent Skills for Cracked Devs and Designers

[![skills.sh](https://skills.sh/b/ramo-dev/skills)](https://skills.sh/ramo-dev/skills)

A growing, open collection of practical skills for AI agents working across
software engineering, product development, and design.

Good work comes from experience, judgment, and attention to detail. These skills
make that knowledge visible and reusable: they give agents concrete methods,
domain context, and standards to work from instead of leaving every decision to
generic prompts.

## Install

Install the collection with the [Skills CLI](https://www.skills.sh/docs):

```sh
npx skills@latest add ramo-dev/skills
```

The CLI will let you choose which skills and agents to install.

## Reference

- **[compasscms-sdk](./skills/compasscms-sdk/SKILL.md)** — Integrate the Compass CMS TypeScript SDK into JavaScript and TypeScript applications, with guidance on API resources, authentication, pagination, and errors.

## Contribute

This collection is open for contribution, scrutiny, and discussion. The skills
are plain Markdown so their guidance can be reviewed, challenged, improved, and
forked. Issues and pull requests are welcome, including new skills for the
collection.

Each skill lives in its own directory under [`skills/`](./skills/). The
collection is licensed under the [MIT License](./LICENSE).
